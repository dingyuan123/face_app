## 一、项目定位与技术栈（已验证事实）

- 项目：「见面聊（FaceTo）」移动客户端；管理后台是独立项目，不在本仓库。
- 技术：UniApp x + Vue 3 + UTS，页面为 `.uvue`（`<script setup lang="uts">`），**不是普通 Vue Web 项目**。
- 渲染：`manifest.json` 已开启 `vapor: true`（Vapor + bytecode 渲染目标）。
- 目标平台：Android、iOS、HarmonyOS、微信小程序；**Android 真机优先验证**。
- 开发环境：HBuilderX `5.26.2026091802`；项目无 `package.json`/npm 依赖/Lint/自动化测试脚本。
- 页面规模：`pages.json` 注册 47 个页面；一级 `tabBar` 5 个（首页、动态、资讯、消息、我的）。
- 品牌主题：珊瑚粉 `#FD5A6B`、渐变中间色 `#FD955E`、暖橙 `#FCAE59`、墨色 `#1F1A17`，暖白背景系；令牌在 `uni.scss`（`$facetof-*`）。

## 五、已知问题与风险（按优先级）

2. 【中】工作区约 30 个文件未提交（API 联调批次），存在丢失风险；建议尽快由用户确认后提交。
3. 【中】`platformConfig.json` 仅 `APP-ANDROID`，与四平台目标不一致；微信小程序 appid 为空，iOS 配置基本为空，HarmonyOS 无独立配置。
